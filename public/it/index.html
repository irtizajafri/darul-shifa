HMS PC Lockdown

Darul Shifa HMS — counter PCs pe internet, USB storage aur software band karna. Sab kaam yahin se, internet ke baghair. Windows 7, 10 aur 11 sab pe chalta hai.

Paste kaise karein: Copy dabayein, phir PowerShell ki neeli window me right-click karein (Windows 7 me Ctrl+V nahi chalta) aur Enter dabayein.

Pehle ek dafa: server PC (192.168.1.100)

  1. Server pe HMS ka naya version deploy ho chuka ho (login wala update).
  2. Server pe Start → "PowerShell" likhein → right-click → Run as administrator, phir yeh chalayein:
    & ([scriptblock]::Create((New-Object Net.WebClient).DownloadString('http://localhost:5173/it/server-setup.ps1.txt')))
    Is se network ke liye website (5173) aur API (5001) khule rahenge, database (5433) network se band ho jayega, aur server sleep nahi hoga. Server ka internet chalta rahega.
  3. Database password badlein (abhi 1234 hai): pgAdmin / psql me ALTER USER postgres WITH PASSWORD 'naya-mazboot-password'; phir hospital-hms-backend\.env me DATABASE_URL me wahi password likhein aur backend restart karein.
  4. Super Admin ka password badalna ho to .env me SUPER_ADMIN_PASSWORD=... likh ke backend restart karein.

Har counter PC pe (ek ek karke)

  1. PC pe Administrator wale login se jayein.
  2. Browser me http://192.168.1.100:5173 kholein — HMS khule aur login ho jaye. (Na khule to ruk jayein, pehle network theek karein.)
  3. Start → "PowerShell" → right-click → Run as administrator, phir:
    Network printer ya printer-sharing wala PC ho to us ka IP saath dein:
  4. Aakhir me "HMS server tak raasta: OK" aur "Internet: band" aana chahiye. Phir PC restart karein.
  5. Staff ka login Standard user ho (Administrator nahi). Isi admin PowerShell me:
    net localgroup Administrators
    List me staff wala naam ho to hatayein (NAAM ki jagah asal naam):
    net localgroup Administrators NAAM /delete
    Naya staff login banana ho (yeh khud Standard hota hai):
    net user staff PASSWORD /add

    Administrator ka password sirf aap ke paas rahe. Apna admin login kabhi Administrators group se na hatayein.

  6. BIOS: PC on hote waqt F2 / Del / F10 (PC ke hisaab se) → BIOS password lagayein aur "Boot from USB" band karein.

Printers seedha (Thermal & Save / Save & Print bina dialog)

Har counter ke liye do qadam. Pehle sirf ek counter pe karke dekhein.

  1. Counter PC pe (Administrator login, PowerShell Run as administrator). Printer USB se laga ho aur us ka driver installed ho. Script poochegi kaunsa printer thermal hai aur kaunsa normal, phir Super Admin ka email / password:
    Aakhir me "Counter tayar" aana chahiye.
  2. Server PC pe (usi Windows user se jis se HMS backend chalta hai, PowerShell Run as administrator):
    & ([scriptblock]::Create((New-Object Net.WebClient).DownloadString('http://localhost:5173/it/server-printers.ps1.txt')))
    Har counter ke printer pe ek test page niklega. Super Admin → Connected PCs me us PC ke aage "Printer ready" aana chahiye.
  3. Counter pe HMS me General OPD → Thermal & Save aur Save & Print chala kar dekhein — koi dialog nahi aana chahiye.

Laal "[X]" aaye to us ki wajah wahi likhi hogi. Aksar: server pe us printer ka 64-bit driver nahi — driver server pe install karke server-printers dobara chalayein. Counter ka IP badle to dono scripts dobara.

Check karein (restart ke baad, staff login se)

  • HMS khule, login ho, slip save ho aur thermal printer pe print ho.
  • Barcode scanner chale, report ka Excel download ho.
  • Google / koi website na khule.
  • USB stick lagayein — na khule. Keyboard, mouse, printer chalte rahein.
  • Koi software install karne pe admin password maange.

Wapas kholna ho (undo)

Counter PC (admin PowerShell), phir restart:

Server:

& ([scriptblock]::Create((New-Object Net.WebClient).DownloadString('http://localhost:5173/it/server-unlock.ps1.txt')))

Dev PC (Mac) pe kuch nahi chalana — yeh sab sirf Windows counter PCs ke liye hai.
